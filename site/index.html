Turn a bug report into a failing Playwright test.

A Chrome extension for testers. Record the bug, click on what is broken, and Bug2Test opens a pull request with a test that fails today and passes once the bug is fixed.

Install (2 min) Try the demo shop

How it works

  1. Record Click Start recording on the page with the bug.
  2. Repeat the bug Click and type as usual. Steps are saved with stable selectors.
  3. Add expect Click the broken element and say what it should show.
  4. Open PR Get tests/bugs/<bug>.spec.ts in a new PR.

What you get

// Generated by Bug2Test. This test should FAIL until the bug is fixed.
// Actual behaviour: Total still shows ₹998
import { test, expect } from '@playwright/test';

test('bug: Cart total does not update', async ({ page }) => {
  await page.goto('/demo/');
  await page.getByTestId('remove-item-2').click();
  await expect(
    page.getByRole('status', { name: 'Cart total', exact: true })
  ).toHaveText('₹499');
});

The PR description also lists the steps, expected vs actual, console errors and failed network calls captured while recording.

Why use it

No more "can't reproduce"

The test is the reproduction. Devs run one command and see the bug.

Bugs stay fixed

Every bug ends with a regression test in the repo, so it cannot come back silently.

Testers ship tests

QA adds real Playwright tests without writing code or learning selectors.

Readable selectors

getByTestId and getByRole first. CSS only as a last resort, marked with a TODO.

Safe by default

Passwords and OTP fields are never recorded. They become env vars. The token stays in your browser.

Small permissions

Asks for the one site you record. Talks only to api.github.com.

Install

  1. Download bug2test.zip from the latest release and unzip it, or build it: npm ci && npm run build.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and pick the unzipped folder (or dist/).
  4. Open Bug2Test Settings: add repo owner, repo name and a fine-grained token with Contents and Pull requests: Read and write.
  5. Set App base URL to your Playwright baseURL (e.g. http://localhost:3000).

Then open the demo shop, remove an item from the cart and record your first bug.
